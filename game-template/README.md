# GameName Reworked

This project uses [C64rework](https://github.com/larspontoppidan/c64rework)
to reverse-engineer GameName and create a faithful standalone C++/SDL2
reimplementation.

The rework is human-directed and utilizes AI-assisted code generation. See
[C64REWORK.md](C64REWORK.md) for the process and goals.

GameName and its original assets remain subject to the rights of their
respective owners. The license of the reimplemented game code must be
determined separately.
